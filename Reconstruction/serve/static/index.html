Upload formats for the FurnitureArranger models
  • Layout SVG: a file of the FurnitureArranger dataset (accepted/<annotator>/<hash>_accepted.svg). Only the layout data embedded in the file is read. The plan is drawn at the dataset's fixed scale, one plan unit per pixel, so plans up to about 240 units across fit the canvas.
  • Layout JSON: an object with floorplan (WKT geometries keyed wall, door, front_door, window, living, ...) and arrangement.furniture (a list of items with type, x, y, angle, bbox_size_x, bbox_size_y). Furniture is only drawn by the model that sees furniture.
  • Images and arrays work as for ResPlan: a drawing in the palette on white, or a map with one channel per class (the legend order). The scale is an assumption for these, so distances in metres are approximate.
  • These models restore walls, doors and windows. Furniture is context only: it is never removed or erased.
Upload formats, and how to turn ResPlan plans into uploads
  • Plan JSON or GeoJSON: one object keyed by ResPlan categories (wall, door, front_door, window, living, bedroom, bathroom, kitchen, storage, balcony, stair). Each value is WKT, a GeoJSON geometry or feature, or a list of coordinate rings. Add area in m² with the inner footprint, as ResPlan does, or metres_per_unit, to get distances in metres.
  • Images: a top-down plan coloured with the drawing palette on a white background. Other sizes are padded to a square and scaled to 256 × 256 pixels.
  • Arrays: a 13 × 256 × 256 map with one channel per class, in the order wall, railing, column, window, door, living, bedroom, bathroom, kitchen, storage, balcony, other_room, stair. Arrays are read without pickle.
  • ResPlan pickle files are not accepted. Run python -m Reconstruction.serve.convert --ids 1 59 --out uploads/ on your own copy to get a JSON, PNG and NPY file for each plan.
The model is a conditional diffusion network that generates only the missing part; the result is your plan plus that part, so nothing you drew is ever erased. Uploads are processed in memory and are not stored.
